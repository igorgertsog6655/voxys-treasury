# VOXYS · Казначейство

Приложение директора Казначейства: задачи, сроки, основной ответственный, текущий исполнитель, этап, следующий шаг, комментарии, история изменений и ссылки на результаты.

## Запуск

Нужен Node.js 24 или новее. Установка зависимостей не требуется.

```powershell
npm start
```

Откройте http://127.0.0.1:4173 в Chrome или Edge. Для проверки: `npm test`.

## Работа с XLSX

### Рабочий файл на GitHub

Кнопка **GitHub XLSX** подключает файл **VOXYS_treasury_tasks.xlsx** в отдельном **Private** репозитории, например `igorgertsog6655/voxys-treasury-data`. Создайте репозиторий с README. В GitHub создайте fine-grained personal access token с доступом только к этому репозиторию и разрешением **Contents: Read and write**. Токен вводится только в форме приложения, не в чат и не в исходники.

При подключении существующий XLSX загружается с GitHub. Если файла нет, приложение предлагает создать его из текущего реестра. Для первоначального переноса десяти задач откройте подготовленный XLSX до подключения GitHub или загрузите его в закрытый репозиторий. Дальше ручной импорт не требуется: при открытии приложения рабочий файл загружается автоматически, а изменения задач, комментариев и справочника записываются в него отдельными коммитами.

Опция «Запомнить доступ в этом браузере» сохраняет токен зашифрованным AES-GCM в IndexedDB; ключ неэкспортируемый и принадлежит этому браузеру. Это защита от хранения токена открытым текстом, а не от вредоносного кода на том же origin. Для отключения используется «Отключить и забыть». В другом браузере подключение настраивается один раз отдельно. Если сохранение доступа отключено, токен существует только в памяти вкладки.

Перед записью проверяются закрытость репозитория и SHA текущей версии файла. При изменении файла в другом браузере запись останавливается. Сохраните локальную копию и нажмите **Обновить с GitHub**, затем повторите необходимые изменения. Автоматического объединения параллельных изменений нет. При ошибке сети локальные изменения остаются в браузере; приложение показывает, что GitHub не обновлён. При следующем запуске такие изменения не заменяются облачной копией без явного решения пользователя. Максимальный размер рабочего XLSX — 900 КБ.

**Скачать XLSX** сохраняет отдельную копию **VOXYS_treasury_tasks.xlsx** в выбранную пользователем папку, не меняя рабочий файл. В Chrome и Edge открывается диалог выбора файла. В браузерах без File System Access API место скачивания определяется настройками браузера. Имя копии можно изменить в диалоге.

### Локальный файл

- **Подключить XLSX** — создаёт новый файл, после чего изменения задач и комментарии автоматически записываются в него. Выберите новое имя. Существующий непустой файл эта команда не перезаписывает.
- **Открыть XLSX** — загружает полный реестр, историю, комментарии и результаты из ранее созданной книги. В Chrome и Edge файл одновременно подключается для последующей записи. При первом сохранении браузер может запросить разрешение на запись.
- **Скачать XLSX** — выгружает весь реестр, независимо от фильтров и текущего представления.

До подключения файла изменения сохраняются в localStorage этого браузера. После перезагрузки страницы нужно снова открыть рабочий XLSX, чтобы подключить автоматическую запись. Статус над реестром показывает, подключён ли файл. При недоступности записи локальная копия сохраняется, а приложение показывает ошибку. Скачайте резервную копию до открытия другой книги.

В браузерах без File System Access API доступны скачивание и импорт. Там нет автоматической записи в локальный файл. Автозапись работает по HTTPS или на localhost.

Книга содержит листы **Задачи**, **История**, **Комментарии**, **Результаты**, **Настройки**. Связь обеспечивается постоянным ID задачи. Срок — дата Excel, время событий — ISO 8601 в UTC, в интерфейсе показывается Новосибирск. Для сохранения целостности нельзя удалять ID, обязательные листы и заголовки. Ссылки — отдельные строки на листе «Результаты». Поддерживается открытие книг формата приложения v1, до 20 МБ. Формулы при импорте запрещены. Значения, начинающиеся с `=`, экспортируются как текст.

Изменения из интерфейса фиксируются в истории. Ручные изменения XLSX вне приложения историю автоматически не создают. Если файл изменён в Excel в течение сессии, последующая автозапись останавливается: скачайте текущую копию, закройте Excel и заново откройте нужную книгу. XLSX не предназначен для одновременной записи из нескольких окон или с разных компьютеров.

В этой версии нет совместного серверного реестра и авторизации сотрудников. Поле автора заполняется пользователем, история не является защищённым аудитом. GitHub хранит код, а не рабочие записи. Рабочие XLSX исключены из Git. Одновременная командная работа потребует отдельного хранилища/сервера с XLSX как переносимой полной выгрузкой.

## GitHub Pages

1. Создайте репозиторий для этого проекта и загрузите исходники в ветку `main`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` выполнит тесты и опубликует статический интерфейс.

Рабочие данные и XLSX не добавляйте в репозиторий или артефакт Pages. Публикация интерфейса сама по себе не предоставляет посетителям доступ к локальным данным другого пользователя.

## Справочник исполнителей

Раздел «Исполнители» содержит ФИО, электронный адрес и должность. При назначении основного ответственного и текущего исполнителя используются списки из справочника. Нового сотрудника можно добавить прямо из карточки задачи. Электронный адрес уникален без учёта регистра; однофамильцы поддерживаются по постоянным ID. Редактирование ФИО обновляет связанные назначения с записью в истории. Архивирование сохраняет существующие назначения, но исключает сотрудника из новых.

XLSX версии 2 включает лист «Исполнители» и ID назначений на листе «Задачи». Старые XLSX версии 1 и локальные записи обновляются автоматически, без потери задач, комментариев и истории. Имена из прежних задач сохраняются как назначения вне справочника до выбора сотрудника. Справочник хранится вместе с рабочими данными, контакты не публикуются в коде сайта. Перед открытием другой книги сохраняйте полную копию XLSX: импорт заменяет также справочник.
